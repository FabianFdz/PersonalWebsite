# EPIC-003 — Projects, contact, and release quality

## Outcome

The portfolio is credible to recruiters and collaborators, accessible, shareable, and ready for production deployment.

## Scope

- Verified project links and contact destinations.
- Accessibility review, production build, metadata, social card, and performance checks.
- Clear configuration notes for CV/contact data not available in the scaffold.

## Acceptance criteria

1. All external links point to human-approved destinations and show safe behavior.
2. The page meets WCAG 2.2 AA expectations for semantics, focus, contrast, and keyboard access.
3. The production build and automated checks pass.
4. Title, description, language, favicon, and social metadata match the visible portfolio.
5. A maintainer can update content and redeploy using the README alone.

## Non-goals

- A contact-message backend.
- User accounts, analytics, or persistent visitor data.
